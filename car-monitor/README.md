# Мониторинг объявлений об авто: Avito, Авто.ру, Drom → Telegram

Бот следит за поисками на **Avito**, **Авто.ру** и **Drom** и сразу присылает в Telegram
каждое новое объявление: фото, цену, пробег, город и кнопку «Открыть объявление».
Если у уже виденного объявления **снизилась цена**, он тоже об этом сообщит.

Что искать, вы задаёте прямо в чате с ботом:

- **текстом** — `toyota camry до 1.5млн` (поиск по Avito, сначала новые);
- **ссылкой** — настройте на сайте любые фильтры (марка, год, пробег, город, коробка, цена),
  скопируйте адрес страницы с результатами и пришлите боту. К ссылке тоже можно дописать
  `от … до …`.

## Как это работает

1. Раз в `CHECK_INTERVAL` секунд (по умолчанию 60) бот открывает первую страницу каждого
   поиска, отсортированную «сначала новые».
2. Всё, что он видел раньше, хранится в `data.db`. Новое объявление (которого ещё не было) —
   сразу уведомление.
3. При добавлении поиска бот запоминает текущую выдачу и ничего из неё не присылает:
   уведомления приходят только о том, что появится после.

Avito и Авто.ру не пускают обычные «скрипты» (отдают капчу или ошибку 429), поэтому бот
открывает их в настоящем браузере Chromium. Профиль браузера (куки) хранится в папке
`browser_profile`, и если сайт всё-таки покажет капчу, её можно один раз решить руками
в окне браузера — дальше бот продолжит сам.

## Установка

Нужен компьютер или сервер, который работает постоянно, и Python 3.10+.

**Важно:** запускайте бот с **российского домашнего** интернета (или российского VPS).
С зарубежных и «серверных» IP Avito и Авто.ру почти сразу показывают капчу.

### 1. Создайте бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя.
2. Он пришлёт токен вида `123456789:AA...` — он понадобится дальше.

### 2. Установка в Docker (рекомендуется, Linux-сервер или ПК)

Нужен Docker (если нет: `curl -fsSL https://get.docker.com | sh`).

```bash
unzip car-monitor.zip
cd car-monitor
sh install.sh 123456789:AA...ваш_токен
```

Скрипт создаст `.env`, соберёт образ (первый раз — несколько минут, качается Chromium)
и запустит контейнер. Бот сам поднимается после перезагрузки сервера.

```bash
docker compose logs -f     # логи
docker compose restart     # перезапуск после правки .env
docker compose down        # остановить
```

База объявлений и профиль браузера лежат в `car-monitor/data/` — не удаляйте её при
обновлении. Обновление: распакуйте новый архив поверх папки и снова `sh install.sh`.

В контейнере браузер работает на виртуальном экране, поэтому решить капчу руками там
нельзя. Если Avito/Авто.ру постоянно пишут о капче — увеличьте `CHECK_INTERVAL` или
укажите российский `PROXY` в `.env`, затем `docker compose restart`.

### 2. Windows (без Docker)

1. Установите Python с [python.org](https://www.python.org/downloads/) — при установке
   поставьте галочку **Add python.exe to PATH**.
2. Скачайте папку `car-monitor` и дважды щёлкните `run.bat`.
   Первый запуск ставит всё нужное (несколько минут), затем откроет `.env` в блокноте.
3. Впишите токен в строку `TELEGRAM_BOT_TOKEN=`, сохраните, снова запустите `run.bat`.

### 2. Linux / macOS (без Docker)

```bash
cd car-monitor
./run.sh          # первый раз создаст .env — впишите туда токен
./run.sh          # запуск
```

На сервере без экрана поставьте в `.env` `BROWSER_HEADLESS=1`.
Если не хватает системных библиотек для браузера:
`.venv/bin/python -m playwright install --with-deps chromium`.

### 3. Пользуйтесь

Найдите своего бота в Telegram, нажмите **Start** — первый, кто напишет боту, становится
его владельцем (чужим он отвечать не будет). Дальше просто присылайте, что искать.

| Команда | Что делает |
|---|---|
| `toyota camry от 800к до 1.2млн` | новый поиск по Avito |
| ссылка с Avito / Авто.ру / Drom | новый поиск по этой выдаче |
| `/list` | список поисков, время последней проверки, ошибки |
| `/del 2` | удалить поиск №2 |
| `/pause 2`, `/resume 2` | приостановить / возобновить |
| `/check` | проверить всё прямо сейчас |

Цены можно писать как `1500000`, `1 500 000`, `1.5млн`, `900к`, `900 тыс`.

## Настройки (`.env`)

| Параметр | По умолчанию | Значение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather |
| `ALLOWED_CHAT_IDS` | пусто | кому ещё разрешён бот (chat id через запятую). Чужой человек, написавший боту, увидит свой chat id — его и вписывайте |
| `CHECK_INTERVAL` | `60` | пауза между проверками, сек. (минимум 20) |
| `AVITO_REGION` | `rossiya` | регион для поиска текстом: `moskva`, `sankt-peterburg`, … |
| `BROWSER_HEADLESS` | `0` | `1` — браузер без окна (для сервера) |
| `BROWSER_CHANNEL` | пусто | `chrome` — использовать установленный Google Chrome |
| `PROXY` | пусто | прокси для сайтов: `http://user:pass@host:port` |

## Советы

- **Скорость vs. капча.** Чем чаще проверки и чем больше поисков, тем выше шанс, что Avito
  начнёт показывать капчу. 60–120 секунд на 5–10 поисков — нормально. Нужно быстрее —
  поставьте второй экземпляр бота на другом компьютере/IP.
- **Узкие поиски лучше широких.** Поиск «вся Россия, все машины» обновляется быстрее, чем
  бот успевает проверять одну страницу (≈50 объявлений), и часть новых он пропустит.
  Фильтруйте по марке/модели/городу/цене.
- Если бот 3 раза подряд не смог проверить поиск, он напишет об этом в Telegram, а когда
  всё наладится — сообщит, что поиск снова работает.
- Сайты время от времени меняют вёрстку. Если парсер перестанет находить карточки, бот
  попробует найти хотя бы ссылки на объявления, а в `/list` появится ошибка — тогда нужно
  поправить селекторы в `carmon/parsers.py`.
- Уважайте правила площадок: бот только читает публичную выдачу с паузами, как человек,
  обновляющий страницу. Не ставьте интервал в несколько секунд.

## Для разработчика

```
monitor.py            точка входа
carmon/app.py         команды бота, цикл проверки, формат уведомлений
carmon/parsers.py     разбор выдачи Avito / Авто.ру / Drom
carmon/fetcher.py     загрузка страниц (requests или Chromium через Playwright)
carmon/db.py          SQLite: поиски и уже виденные объявления
carmon/telegram.py    минимальный клиент Telegram Bot API
Dockerfile, docker-compose.yml, install.sh   установка в Docker
tests/                тесты на сохранённых страницах: python -m unittest discover tests
```

Новая площадка добавляется так: функция разбора в `parsers.py` (+ регулярка ссылки на
объявление в `AD_LINK_RE` и домен в `detect_source`), селектор карточки в
`fetcher.CARD_SELECTOR`.
