# Бот «Буржуй клаб, помощник»

Telegram-бот банного комплекса «Буржуй клаб» (Подольск).

- Меню на кнопках: залы на часы, жильё на сутки, частые вопросы, адрес, Провинция, администратор.
- Бронирование по шагам: зал → дата → время → часы → гости → итоговая цена → телефон → заявка в группу администраторов.
- Цены считает код по `data/ceny.json`, а не ИИ. Монарх помечен закрытым на ремонт.
- Посуточно (Виконт, студия): расчёт и кнопка онлайн-бронирования RealtyCalendar.
- Администраторы отвечают гостю прямо из группы: ответить (reply) на сообщение бота.
- Гость прислал чек — бот благодарит и пересылает чек в группу.
- Свободный текст: с ключом Claude API отвечает ИИ по `data/baza_znaniy.md` и считает цены через инструменты; без ключа — разбор по ключевым словам.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_CHAT_ID
python -m bot.main
```

Зависимость только одна — `anthropic` (нужна, если задан `ANTHROPIC_API_KEY`). Telegram — на стандартной библиотеке.

`ADMIN_CHAT_ID`: добавить бота в группу администраторов и написать в ней `/id`.

## Фото

Положить фото в `media/<зал>/` (`baron`, `markiz`, `gercog`, `monarh`, `vikont`, `studio`), до 10 штук, порядок — по имени файла. Если папки нет, бот даёт ссылку на сайт.

## Цены и тексты

- `data/ceny.json` — все цены и правила расчёта.
- `bot/texts.py` — карточки залов и ответы на частые вопросы.
- `data/baza_znaniy.md` — база знаний для ИИ.
